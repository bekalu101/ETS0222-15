1. add()
Adds a single element to a set.
2. update()
Adds multiple elements (from another iterable) to a set.
3. remove()
Removes a specific element; raises error if not found.
4. discard()
Removes a specific element; no error if element not found.
5. pop()
Removes and returns a random element.
6. clear()
Removes all elements from the set.
7. union()
Returns a new set with elements from both sets.
8. intersection()
Returns common elements in both sets.
9. difference()
Returns elements in the first set but not in the second.
10. issubset() / issuperset() / isdisjoint()
Check set relationships.
